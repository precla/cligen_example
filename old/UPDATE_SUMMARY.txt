WHAT WAS CHANGED
════════════════════════════════════════════════════════════════════════════

The CLI now supports IP address configuration with dynamic interface discovery.

OLD COMMAND:
  cli> ip
  [Shows table of all interfaces]

NEW COMMAND FORMAT:
  cli> ip                               # Show available interfaces
  cli> ip <interface> <ip_address>      # Configure IP on interface


NEW FEATURES
════════════════════════════════════════════════════════════════════════════

1. DYNAMIC INTERFACE LISTING
   ─────────────────────────
   When user types 'ip', it shows:

   [Loading interfaces from system...]
   [Available interfaces to configure:]

     lo                 (UP   )  Currently: 127.0.0.1
     ens192             (UP   )  Currently: 172.16.222.109
     docker0            (UP   )  Currently: 172.17.0.1

   Usage: ip <interface> <ip_address>
   Example: ip eth0 192.168.1.100


2. IP CONFIGURATION WITH VALIDATION
   ───────────────────────────────────
   User types: ip ens192 192.168.1.100

   Output:
   ✓ IP Configuration
     Interface: ens192
     IP Address: 192.168.1.100
     Status: Would be applied

     [Note: This is a simulation. In a real system,
      this would run: ip addr add 192.168.1.100/24 dev ens192]


3. ERROR HANDLING
   ────────────────

   Invalid Interface:
     cli> ip nonexistent 192.168.1.1
     Error: Interface 'nonexistent' not found
     Available interfaces: lo, ens192, docker0

   Invalid IP Format:
     cli> ip ens192 invalid.ip
     Error: Invalid IPv4 address format: 'invalid.ip'
     Expected format: XXX.XXX.XXX.XXX (e.g., 192.168.1.100)


HOW IT WORKS
════════════════════════════════════════════════════════════════════════════

Step-by-Step Execution:

1. User types: ip ens192 192.168.1.100
                    ↓
2. CLI calls: handle_ip_command(input)
                    ↓
3. Function:
   • Calls get_interfaces() → Query OS for interfaces
   • Parses arguments: interface="ens192", ip="192.168.1.100"
   • Validates: Is 'ens192' a real interface? YES
   • Validates: Is '192.168.1.100' valid IPv4? YES
   • Displays: Success message with what would be applied
                    ↓
4. Returns to CLI prompt


KEY IMPLEMENTATION DETAILS
════════════════════════════════════════════════════════════════════════════

NEW FUNCTIONS ADDED:

1. handle_ip_command(const char *input)
   - Parses 'ip <interface> <ip_address>'
   - Loads interfaces dynamically
   - Validates input
   - Shows appropriate messages

   Location: simple_cli.c, line ~139

2. is_valid_ipv4(const char *ip)
   - Validates IPv4 address format
   - Uses standard inet_aton()
   - Returns 1 (valid) or 0 (invalid)

   Location: simple_cli.c, line ~180

3. interface_exists(const char *ifname, ...)
   - Checks if interface exists in discovered list
   - Returns 1 (exists) or 0 (not found)

   Location: simple_cli.c, line ~190

MODIFIED FUNCTIONS:

1. main()
   - Changed from strcmp() to strncmp() for "ip" matching
   - Now handles: "ip", "ip eth0", "ip eth0 192.168.1.1"
   - Calls handle_ip_command() for all variants

2. show_help()
   - Updated to show new command format
   - Includes examples

  - Manual validation code

With CLIgen:
  - Automatic parsing (lexer + parser)

  - Auto-generated error messages
  - Automatic tab-completion
  - Hierarchical menus possible
  - Less code, more features
