THE GOAL
════════

Create a CLI that:
  ✓ Runs in an endless loop
  ✓ Waits for user input
  ✓ When user enters "ip", dynamically loads and shows network interfaces
  ✓ Shows real data (not hardcoded)

════════════════════════════════════════════════════════════════════════════

1. COMPILE
──────────

2. RUN

WHAT YOU'VE DONE
════════════════

You just saw DYNAMIC INTERFACE LOADING - the core power of CLIgen!

  ✓ User entered: ip
  ✓ Program called: getifaddrs() (OS system call)
  ✓ OS returned: Your actual interfaces
  ✓ Program displayed: Formatted table
  ✓ Data was: FRESH FROM THE OS, not hardcoded

This is why CLIgen is powerful - it automates this pattern!


HOW IT WORKS
════════════

Step-by-step:

    User types "ip"
           ↓
    CLI calls get_interfaces()
           ↓
    getifaddrs() queries OS: "What interfaces exist?"
           ↓
    OS returns: lo, ens192, docker0
           ↓
    Program displays in nice table
           ↓
    Returns to prompt: "cli> "

THE CONCEPT VISUALIZED
═══════════════════════════════════════════════════════════════════════════

WITHOUT Dynamic Loading (BAD):
  ────────────────────────────

  CLI Source Code:
  ┌──────────────────────────┐
  │ char *if[] = {           │
  │   "eth0",                │
  │   "eth1",                │
  │   "docker0"              │
  │ };                       │
  │                          │
  │ // Recompile if you add  │
  │ // a new interface!      │
  └──────────────────────────┘

  Problem: Hardcoded, static, must recompile


WITH Dynamic Loading (GOOD - This Program):
  ───────────────────────────────────────────

  CLI Runtime:
  ┌──────────────────────────┐
  │ getifaddrs()  ←── Query  │
  │      ↓              OS   │
  │ System returns:          │
  │   lo, ens192, docker0    │
  │      ↓                   │
  │ Display in table         │
  │                          │
  │ // Works everywhere!     │
  │ // No recompilation!     │
  └──────────────────────────┘

  Benefit: Automatic, flexible, portable

KEY FUNCTIONS IN CODE
═══════════════════════════════════════════════════════════════════════════

getifaddrs()
  • What: Query OS for interfaces
  • Where: simple_cli.c, line 27
  • How: Standard C library function
  • Result: List of all interfaces
  • Key: This is what makes it DYNAMIC

get_interfaces()
  • What: Wrapper around getifaddrs()
  • Where: simple_cli.c, line 27-57
  • How: Populates interface_info array
  • Result: Array of interface data
  • Key: Called every time user types "ip"

display_interfaces()
  • What: Format and display the table
  • Where: simple_cli.c, line 59-79
  • How: ASCII art formatting
  • Result: Pretty output
  • Key: Makes it user-friendly

main()
  • What: The CLI loop
  • Where: simple_cli.c, line 117+
  • How: Read input → process command → repeat
  • Result: Interactive experience
  • Key: Classic CLI pattern
