════════════════════════════════════════════════════════════════════════════════
KEY LEARNING POINTS
════════════════════════════════════════════════════════════════════════════════

1. DYNAMIC VS HARDCODED
   ─────────────────────
   Without dynamic loading:
     char *if[] = {"eth0", "eth1"};  // Must recompile if you add wlan0

   With dynamic loading:
     getifaddrs();  // Query OS at runtime, works everywhere

2. THE CORE CONCEPT OF CLIGEN
   ──────────────────────────
   This program shows what CLIgen does automatically:
   - Accept user input
   - Process commands
   - Dynamically load data
   - Display formatted output

3. WHY IT MATTERS
   ────────────────
   - Works on any system
   - Always shows real data
   - No recompilation needed
   - Portable and maintainable
